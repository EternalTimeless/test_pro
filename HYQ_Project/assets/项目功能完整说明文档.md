### 1.1 Singleton - 单例基类

**文件位置**: `assets/Script/Base/Singleton.ts`

**功能说明**:
提供单例模式的基类，用于创建全局唯一的实例。

**使用方法**:
```typescript
export default class MyManager extends Singleton {
    public static get instance() {
        return this.getInstance<MyManager>();
    }

    private constructor() {
        super();
        // 初始化逻辑
    }
}

// 使用
MyManager.instance.某个方法();
```

**典型应用**: 所有管理器类（EventManager、PoolManager、AudioManager等）

### 1.2 EventManager - 事件管理器

**文件位置**: `assets/Script/Base/EventManager.ts`

**功能说明**:
实现发布-订阅模式的事件系统，支持跨模块通信。

**核心方法**:
- `on(eventName, func, ctx?, once?)`: 监听事件
- `off(eventName, func)`: 取消监听
- `emit(eventName, ...params)`: 触发事件
- `clear()`: 清空所有事件

**使用示例**:
```typescript
import { EventManager } from './Base/EventManager';

// 定义事件名称
const GAME_WIN = 'GAME_WIN';
const PLAYER_DIE = 'PLAYER_DIE';

// 1. 监听事件
EventManager.instance.on(GAME_WIN, this.onGameWin, this);
EventManager.instance.on(PLAYER_DIE, this.onPlayerDie, this);

// 2. 触发事件
EventManager.instance.emit(GAME_WIN, score, stars);

// 3. 一次性事件
EventManager.instance.on(SPECIAL_EVENT, callback, this, true);

// 4. 取消监听
EventManager.instance.off(GAME_WIN, this.onGameWin);

// 5. 清空所有事件
EventManager.instance.clear();

// 回调函数
onGameWin(score: number, stars: number) {
    console.log(`游戏胜利！得分：${score}，星级：${stars}`);
}
```

**典型应用场景**:
- 游戏状态变更通知
- UI更新事件
- 玩家行为事件（死亡、升级等）
- 系统间解耦通信

### 1.3 PoolManager - 对象池管理器

**文件位置**: `assets/Script/Base/PoolManager.ts`

**功能说明**:
管理游戏对象的复用，避免频繁创建销毁，提升性能。

**核心方法**:
- `getPool<T>(key)`: 从池中获取对象
- `setPool(key, node)`: 将对象回收到池中

**使用示例**:
```typescript
import { PoolManager } from './Base/PoolManager';
import { PoolEnum, PropEnum } from './Base/EnumList';

// 1. 从对象池获取金币道具
const key = PoolEnum.Prop + PropEnum.gold;
const coin = PoolManager.instance.getPool<Node>(key);

if (!coin) {
    // 池中没有，创建新的
    const coinPrefab = PrefabsManager.instance.GetPrefabsIns(
        PrefabsEnum.prop,
        PropEnum.gold
    );
    // 初始化金币...
}

// 2. 使用金币...

// 3. 将金币回收到对象池
PoolManager.instance.setPool(key, coin);
```

**对象池键名规范**:
```
{PoolEnum.Type} + {具体枚举}

示例：
- PoolEnum.Prop + PropEnum.gold      -> 金币
- PoolEnum.EffectSq + EffectEnum.hit  -> 击中特效
- PoolEnum.bullet + BulletEnum.arrow  -> 箭矢子弹
```

**典型应用场景**:
- 子弹对象池
- 特效对象池
- 道具对象池
- 敌人对象池

### 1.4 AudioManager - 音频管理器

**文件位置**: `assets/Script/Base/AudioManager.ts`

**功能说明**:
单例模式，管理游戏中所有音频播放。

**核心方法**:
- `playOneShot(sound, volume)`: 播放短音效（打击、爆炸等）
- `play(sound, volume)`: 播放长音频（背景音乐）
- `stop()`: 停止播放
- `pause()`: 暂停
- `resume()`: 恢复

**使用示例**:
```typescript
import { AudioManager } from './Base/EventManager';
import { SoundEnum } from './Base/EnumList';

// 1. 播放背景音乐（循环）
AudioManager.inst.play(SoundEnum.bgm, 0.5);  // 音量50%

// 2. 播放短音效
AudioManager.inst.playOneShot(SoundEnum.sound_buyup, 1.0);

// 3. 播放胜利音效
AudioManager.inst.playOneShot(SoundEnum.gameWin, 0.8);

// 4. 暂停背景音乐
AudioManager.inst.pause();

// 5. 恢复播放
AudioManager.inst.resume();

// 6. 停止播放
AudioManager.inst.stop();
```

**典型应用场景**:
- 背景音乐播放
- 打击音效
- UI点击音效
- 技能音效

**使用示例**:
```typescript

const groundLayer = LayerManager.instance.getLayer(LayerEnum.Layer_1_Ground);

groundLayer.addChild(player);
```

**典型应用场景**:
- 2D游戏渲染层级管理
- UI层级排序

### 2.2 近战攻击 (MeleeAttack)

**文件位置**: `assets/Script/functionS/Battle/Attack/MeleeAttack.ts`

**功能说明**:
实现近战单体攻击，支持伤害和击退效果。

**主要属性**:
- `power`: 伤害值
- `reoel`: 击退力度
- `attackSpeed`: 攻击速度（次/秒）
- `collectGettarget`: 目标收集器

**使用示例**:
```typescript
import { MeleeAttack } from './functionS/Battle/Attack/MeleeAttack';

// 1. 在角色上添加组件
const meleeAttack = playerNode.addComponent(MeleeAttack);

// 2. 配置攻击属性
meleeAttack.power = 50;      // 伤害50
meleeAttack.reoel = 30;      // 击退力度30
meleeAttack.attackSpeed = 1.5; // 每秒攻击1.5次

// 3. 执行攻击（会在update中自动根据attackSpeed执行）
meleeAttack.attack();

// 4. 手动触发攻击事件
meleeAttack.attackEvent(50, 30);

// 攻击流程：
// 1. 从collectGettarget获取最近的目标
// 2. 对目标调用target.Hit(power)造成伤害
// 3. 对目标调用target.repelBattleTarget(sourceNode, reoel)击退
```

**典型应用场景**:
- 剑士攻击
- 怪物近战
- 格斗游戏

### 3.3 抛物线跳跃 (jumpParabola) ⭐推荐

**数学原理**:
```
X/Z轴：线性插值
Y轴：线性插值 + 抛物线偏移
```

**使用示例**:

```typescript
    100,         // 跳跃高度100单位
    1.5          // 耗时1.5秒
);

// 2. 带回调的跳跃
JumpManager.instance.jumpParabola(player, targetPos, 100, 1.5)
    .onComplete(() => {
        console.log('跳跃完成！');
        // 播放落地音效
        AudioManager.inst.playOneShot(SoundEnum.land);
    })
    .setDelay(0.5);  // 延迟0.5秒开始

// 3. 使用曲线调制

    .setCurveRange(myCurve);  // 自定义曲线
```

### 6.2 RockerManager - 摇杆管理器

**文件位置**: `assets/Script/functionS/Rocker/RockerManager.ts`

**功能说明**:
单例模式，提供摇杆输入的全局访问。

**主要属性**:
- `rockerDirection`: 摇杆方向向量 {x, y}
- `isMove`: 是否正在使用摇杆

**使用示例**:
```typescript
import { RockerManager } from '../functionS/Rocker/RockerManager';

// 1. 获取摇杆方向
const direction = RockerManager.instance.rockerDirection;
// direction.x: -1到1（左到右）
// direction.y: -1到1（下到上）

// 2. 检查是否移动
if (RockerManager.instance.isMove) {
    console.log('玩家正在移动');
}

// 3. 控制角色移动
update(dt: number) {
    if (RockerManager.instance.isMove) {
        const dir = RockerManager.instance.rockerDirection;
        this.node.position.x += dir.x * this.speed * dt;
        this.node.position.y += dir.y * this.speed * dt;
    }
}
```

### 6.3 摇杆完整示例

```typescript
import { _decorator, Component, Vec3 } from 'cc';
import { RockerManager } from '../functionS/Rocker/RockerManager';

const { ccclass, property } = _decorator;

@ccclass('PlayerController')
export class PlayerController extends Component {

    @property
    moveSpeed: number = 300;

    update(dt: number) {
        // 1. 获取摇杆输入
        if (RockerManager.instance.isMove) {
            const dir = RockerManager.instance.rockerDirection;

            // 2. 移动角色
            this.node.position.x += dir.x * this.moveSpeed * dt;
            this.node.position.y += dir.y * this.moveSpeed * dt;

            // 3. 角色朝向
            if (dir.x > 0.1) {
                // 向右
                this.node.scale.x = 1;
            } else if (dir.x < -0.1) {
                // 向左
                this.node.scale.x = -1;
            }
        }
    }
}
```
