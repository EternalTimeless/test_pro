# 默认命名规则配置说明

## 配置文件

### defaultNamingRules.json

这个文件定义了扩展的默认命名规则列表。当用户首次使用扩展或选择重置为默认规则时，系统会从这个文件加载预设的命名规则。

#### 配置文件结构

```json
{
  "version": "1.0.0",
  "description": "默认命名规则配置列表",
  "defaultRules": [
    {
      "name": "规则名称",
      "normalTemplate": "普通版本命名模板",
      "tceTemplate": "TCE版本命名模板", 
      "separator": "分隔符",
      "configItems": [
        {
          "key": "键名",
          "label": "显示名称",
          "value": "默认值",
          "required": true|false,
          "description": "描述信息"
        }
      ]
    }
  ]
}
```

#### 模板语法

命名模板使用 `{键名}` 作为占位符，系统会在生成文件名时替换为对应的值：

- `{gameAbbr}` - 游戏名称缩写
- `{packageDate}` - 打包日期
- `{adName}` - 试玩广告名称
- `{separator}` - 分隔符
- 等等...

#### 预设规则

当前配置文件包含以下5种预设规则：

1. **标准游戏命名规则** - 包含完整的配置项
2. **简化命名规则** - 只包含核心配置项
3. **详细命名规则** - 包含版本号、构建类型等详细信息
4. **Facebook专用规则** - 针对Facebook平台的特殊命名格式
5. **TikTok专用规则** - 针对TikTok平台的特殊命名格式

## 使用方法

### 1. 首次使用

扩展会自动从配置文件加载默认规则列表，无需手动操作。

### 2. 重置为默认规则

在命名规则配置对话框中：

1. 点击"重置默认规则"按钮
2. 确认操作
3. 系统会覆盖当前所有规则，恢复为配置文件中定义的默认规则

### 3. 自定义默认规则

如果需要修改默认规则列表：

1. 编辑 `configs/defaultNamingRules.json` 文件
2. 按照JSON格式添加、修改或删除规则
3. 保存文件
4. 在扩展中点击"重置默认规则"即可应用新的配置

## 注意事项

1. **配置项键名唯一性**: 每个规则中的配置项键名（key）在同一规则内必须唯一
2. **必填项验证**: 标记为 `required: true` 的配置项在使用时必须填写
3. **模板格式**: 确保模板中的占位符与配置项的键名匹配
4. **JSON格式**: 配置文件必须是有效的JSON格式，注意逗号和引号的使用
5. **文件位置**: 不要移动或重命名配置文件，系统依赖固定路径加载

## 配置项说明

### 常用配置项键名

- `gameAbbr`: 游戏名称缩写
- `packageDate`: 打包日期（YYYYMMDD格式）
- `adName`: 试玩广告名称
- `plannerAbbr`: 策划名字缩写
- `plannerName`: 策划全名
- `companyPrefix`: 公司前缀
- `platformName`: 平台名称（自动生成）
- `version`: 版本号
- `buildType`: 构建类型
- `creativeId`: 创意ID

### 分隔符选择

常用分隔符：
- `_` (下划线) - 最常用
- `-` (连字符)  
- `.` (点号)
- 空字符串 - 无分隔符

根据不同平台的要求选择合适的分隔符。
